# UI language (i18n)

gea's CLI output is bilingual. Every user-facing string lives in
`src/gea/i18n/{es,en}.json`, keyed the same way in both files (a test
enforces that the key sets match). Code calls `gea.i18n.t("some.key",
**vars)` — never hardcodes a string in a print statement.

Resolution order (`gea.i18n.current_lang()`):

1. `GEA_LANG` env var, if it's `es` or `en`.
2. `ui_lang` in `~/gea/config.json`.
3. `es` (the default/recommended language).

`gea setup`'s first question sets `ui_lang`. Project-generated docs (the
templates `gea init` writes) additionally respect `gea.json`'s
`lang.docs`, independent of the CLI's own `ui_lang` — a team can run gea in
English while generating Spanish docs for their project, or vice versa.
